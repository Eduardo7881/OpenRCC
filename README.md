# Roblox RCC PHP

Backend-only PHP interface for the 2016 RCCService source supplied with this project.

It is intentionally a library, not a website or control panel.

## What it wraps

The supplied RCC WSDL exposes:

- HelloWorld
- GetVersion
- GetStatus
- OpenJob / OpenJobEx
- RenewLease
- Execute / ExecuteEx
- CloseJob
- BatchJob / BatchJobEx
- GetExpiration
- GetAllJobs / GetAllJobsEx
- CloseExpiredJobs
- CloseAllJobs
- Diag / DiagEx

The PHP class also adds revival-oriented helpers:

- `renderPlaceThumbnail()`
- `renderWithScript()`
- `startGameServer()`
- `stopGameServer()`
- `thumbnailClickScript()`

## Requirements

- PHP 8.1+ recommended
- DOM/XML extension
- cURL recommended, but the class has a PHP stream fallback
- An RCCService build compatible with the 2016 SOAP contract

The RCC build in the supplied source binds to port **64989 by default**. The constructor lets the revival override the host/port.

## Include it in an existing backend

```php
require_once __DIR__ . '/RCC/src/RCCService.php';

use Roblox\RCC\RCCService;

$rcc = new RCCService('127.0.0.1', 64989);

echo $rcc->getVersion();
```

No website, router, HTML, session or database is required.

## Execute code in a job

```php
$rcc->openJobEx(
    'my-job',
    'return "hello from RCC"',
    [],
    300
);

$result = $rcc->executeEx(
    'my-job',
    'return 123, true, "abc"'
);

$rcc->closeJob('my-job');
```

`executeEx()` returns decoded PHP values:

```php
[123, true, 'abc']
```

## Render a place

```php
$baseUrl = 'http://127.0.0.1:80';

$pngBase64 = $rcc->renderPlaceThumbnail(
    12345,
    $baseUrl,
    420,
    420,
    false,
    true,
    'PNG'
);

file_put_contents(
    __DIR__ . '/thumb.png',
    base64_decode($pngBase64, true)
);
```

The helper uses the 2016 source's five-argument signature:

```lua
ThumbnailGenerator:Click(format, width, height, hideSky, crop)
```

For avatar rendering or custom model setup, use `renderWithScript()` and build the Lua script yourself.

## Start a 2016 game server

Load the supplied `gameserver.txt` once:

```php
$gameServerScript = file_get_contents(__DIR__ . '/gameserver.txt');

$rcc->startGameServer(
    'game-123',
    12345,
    53640,
    'http://127.0.0.1:80',
    $gameServerScript
);
```

Stop it:

```php
$rcc->stopGameServer('game-123');
```

The job ID should be unique per running server.

## "Enter game server"

RCCService itself does not expose a SOAP operation called "join/enter game server".

The separation should normally be:

1. PHP backend asks RCC to create/start the game-server job.
2. The game server listens on its configured Roblox network port.
3. Your revival's game/session layer gives the client the server address/job information.
4. RCC is used by the backend for lifecycle management, execution and leases.

This library therefore exposes `startGameServer()` and `stopGameServer()` rather than inventing a fake RCC `JoinGame` API.

## Universal/custom RCC calls

If a particular 2016 build adds or differs from the supplied contract, the low-level method is available:

```php
$response = $rcc->call('GetVersion');
```

Or:

```php
$response = $rcc->call('SomeOperation', [
    'value' => 'test'
]);
```

The SOAP endpoint can also be changed simply by constructing another instance:

```php
$rcc = new RCCService('10.0.0.20', 64989);
```

## Important

The WSDL shipped in the supplied source defines the SOAP contract but does not contain a service URL. That is why this library takes `host` and `port` directly instead of relying on `SoapClient`'s WSDL endpoint.

The supplied C++ source shows the default RCC port as `64989`.

This library does not patch RCC, bypass its trust checks, or emulate RCC. It is only the PHP-side client for an RCC instance you operate.


## Additional backend helpers

The library also provides higher-level helpers around the raw RCC contract:

```php
$rcc->isAlive();
$rcc->health();

$rcc->getJob('game-server-123');
$rcc->jobExists('game-server-123');
$rcc->getJobs();
$rcc->getJobs(1);

$rcc->renewJob('game-server-123', 600);
$rcc->closeJobIfExists('game-server-123');
$rcc->ensureJob('job-id', $script);
```

`health()` returns:

```php
[
    'online' => true,
    'endpoint' => 'http://127.0.0.1:64989/',
    'version' => '...',
    'environmentCount' => 3
]
```

### One-shot RCC execution

For tasks that do not need a persistent job:

```php
$result = $rcc->run(
    'return "generated by RCC"',
    [],
    'BackendTask'
);
```

This uses the real RCC `BatchJobEx` operation.

### Texture thumbnails

The 2016 `ThumbnailGenerator` also exposes `ClickTexture`:

```php
$png = $rcc->renderTextureThumbnail(
    'http://www.roblox.com/asset/?id=123456',
    420,
    420,
    'PNG'
);
```

This is separate from place/model rendering.

### Diagnostics

The source implements diagnostic flags as a bitmask:

```php
$rcc->diagnose(RCCService::DIAG_PERFORMANCE);

$rcc->diagnose(
    RCCService::DIAG_LEAK_DUMP |
    RCCService::DIAG_PERFORMANCE
);
```

Available constants:

```text
DIAG_LEAK_DUMP       = 1
DIAG_ALLOCATION_TEST = 2
DIAG_PERFORMANCE     = 4
```

These are intended for RCC maintenance/debugging. They should not be called for every player request.
